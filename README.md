# 42 Lisboa — Piscine (Part 1)

This repository preserves exercises I completed during the **42 Lisboa Piscine**, an intensive introduction to programming and the 42 peer-learning methodology.

## Contents

The repository is organised into exercise folders:

- **Shell00 and Shell01** — introductory shell exercises.
- **C00–C08** — C programming exercises covering progressively more advanced fundamentals.
- **SUBJECTS** — exercise subject materials included with the original work.

## Skills Practised

- C programming fundamentals
- Shell commands and working in a terminal
- Functions, control flow and iteration
- Pointers, strings and arrays
- Problem-solving, debugging and independent learning

## About This Work

The Piscine is an intensive, project-based selection and learning experience at 42. This repository is a record of my exercises from that period, preserved as part of my technical learning journey.

The work is historical and has not been rewritten as a modern software project.
